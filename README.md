One letter for my day: **L** — lazy. A couch day, no plans, nothing achieved on purpose. The letter is the whole entry: exactly one character, A to Z, standing for the word that describes the day.

## Run it

```sh
node main.ts
```

This writes a single letter (`L`) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
